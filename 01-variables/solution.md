# JavaScript Variables - Output Solutions

---

## Question 1

### Code

```javascript
let name = "Swati";
console.log(name);
```

### Output

```text
Swati
```

### Explanation

The variable `name` stores the string `"Swati"`. `console.log()` prints its value.

---

## Question 2

### Code

```javascript
let age = 25;
age = 30;
console.log(age);
```

### Output

```text
30
```

### Explanation

`let` allows reassignment. The value changes from `25` to `30`.

---

## Question 3

### Code

```javascript
const country = "India";
console.log("Country:", country);
```

### Output

```text
Country: India
```

### Explanation

`console.log()` prints both arguments separated by a space.

---

## Question 4

### Code

```javascript
let score = 40;
score = score + 15;
console.log(score);
```

### Output

```text
55
```

### Explanation

The current value (`40`) is increased by `15`, resulting in `55`.

## Question 5

### Code

```javascript
const language = "JavaScript";
console.log("Learning " + language);
```

### Output

```text
Learning JavaScript
```

### Explanation

The `+` operator concatenates (joins) two strings.
